# Документация проекта: Учёт ПК и Оргтехники

Добро пожаловать в техническую и пользовательскую документацию проекта. Приложение представляет собой десктопную программу, построенную на фреймворке **Wails**, которая объединяет мощь языка **Go** для работы с файловой системой и операционной системой, и **React + TypeScript** для создания отзывчивого и современного пользовательского интерфейса.

## Структура документации

1. [Архитектура приложения (architecture.md)](architecture.md)
   Описание технического стека, взаимодействия Frontend и Backend, структуры папок и компонентов.
2. [Бизнес-логика и Сущности (business_logic.md)](business_logic.md)
   Подробное описание логики работы с оборудованием, лицензиями, поэтажным планом, а также принципы разграничения прав (Режим просмотра / Режим редактирования).
3. [Хранение данных (data_storage.md)](data_storage.md)
   Как устроено хранение данных в едином JSON-файле, механизм атомарной записи, использование `.data.lock` файла для конкурентного доступа в сети.
4. [Инструкция для разработчика (development.md)](development.md)
   Команды для запуска, нюансы сборки под Linux (включая флаги `webkit2_41`), рекомендации по добавлению нового функционала.

## Основные особенности системы
* **Portable (переносимость):** База данных полностью автономна и представляет собой один `.json` файл.
* **Сетевой режим:** Поддержка работы нескольких пользователей с одним файлом на сетевом диске (защита через lock-файл).
* **Модульность:** Каждая логическая сущность (Комплектующие, Лицензии) реализована независимо, но связана через строгие ID.
* **Нативность:** Взаимодействие с системными диалогами ОС (выбор файлов, сохранение отчетов) обрабатывается на уровне Go.
