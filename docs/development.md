# Инструкция для разработчика (Development)

В этом документе описаны правила локальной разработки, сборки и расширения функционала.

## Окружение
Вам понадобятся:
- **Go** >= 1.20
- **Node.js** >= 18 (и npm)
- **Wails CLI** (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)

### Особенности Linux
На многих дистрибутивах Linux (в частности Ubuntu/Debian) Wails 2 требует специфичную версию `webkit2gtk-4.0`. В современных ОС по умолчанию поставляется версия `4.1`.
Чтобы решить проблему несовместимости библиотек:
1. Установите заголовки разработчика: `sudo apt-get install libwebkit2gtk-4.0-dev`.
2. Всегда собирайте и запускайте проект с тегом `-tags "webkit2_41"`.

## Запуск в режиме разработчика (Dev)
Для вашего удобства в корне проекта создан `Makefile`.
```bash
# Запуск режима разработчика (горячая перезагрузка)
make dev
```
Команда `make dev` автоматически пробрасывает нужные теги компилятора (`webkit2_41`), поднимает Vite-сервер на порту 34115 и компилирует Go-бэкенд. Любые изменения в React или Go автоматически обновляют приложение.

## Сборка релиза
```bash
# Сборка готового бинарного файла под Linux
make build-linux

# Сборка под Windows (требует установленного mingw-w64 на Linux или нативного Windows)
make build-windows
```
Готовый бинарный файл `counting-embroidery-threads` появится в папке `build/bin/` (или в корне, если переопределено в Makefile).

## Добавление нового функционала

Если вам нужно добавить новую страницу или сущность (например, "Расходники"):
1. **Go Модели**: Добавьте структуру `Consumable` в `internal/models/store.go` и обновите `DataStore`.
2. **Go CRUD**: В файле `app.go` напишите методы `AddConsumable`, `UpdateConsumable` и `DeleteConsumable`. Обратите внимание: *обязательно проверяйте `a.editMode` перед изменением данных*.
3. **Wails Bindings**: Запустите `make dev` (или пересоберите проект), чтобы Wails сгенерировал новые TypeScript-биндинги в папке `frontend/wailsjs`.
4. **React Типы**: Обновите `frontend/src/types/index.ts`, чтобы он соответствовал изменениям в Go.
5. **React Компоненты**: Создайте новый UI-компонент, импортируйте методы из `wailsjs/go/main/App` и вызовите `reloadData()` из `AppContext` после сохранения.
